Zero‑knowledge

Encrypt/decrypt happens locally in your browser. The server stores ciphertext only. The key is in the URL fragment (#k=…), which is not sent to the server.

Reality check
  • If someone gets the full link (including #k=…), they can decrypt.
  • Passphrase mode helps if you think the link might be forwarded.
  • Burn-on-read is best-effort. People can still screenshot/copy.
